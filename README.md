# Pipo y los Planetas 🚀

Juego educativo de matemáticas para niños de 5 y 6 años: contar, reconocer números hasta 20, formas, patrones, más/menos/igual, secuencias, sumas y restas hasta 10.

- Todo en un único archivo (`index.html`): sin librerías, sin anuncios, sin compras y sin recoger datos.
- Pipo habla en español (3 voces a elegir) y funciona sin conexión una vez cargado.
- Zona de padres: en el mapa, mantener pulsado ⚙️ durante 3 segundos.

**Jugar:** abre la página de GitHub Pages de este repositorio en el móvil, la tablet o el PC.
